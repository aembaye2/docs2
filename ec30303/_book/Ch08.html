1  Chapter 8: Production

Study Guide and Practice (Intermediate Micro)

1.1 Main Summary

The chapter explains how a firm turns inputs into output. Its main ideas are:

  1. The production function links inputs (capital, labor, land, technology, and so on) to the maximum output they can produce.
  2. Short run vs. long run: in the short run at least one input is fixed. In the long run every input can change.
  3. Diminishing returns: in the short run, adding more of one variable input to fixed inputs eventually adds less and less output.
  4. Total, average, and marginal product are three linked ways to describe output per unit of a variable input.
  5. Efficient allocation: a divisible input should go where its marginal product is highest, which means its marginal product is equal across activities at the optimum.
  6. Isoquants show all input combinations that produce the same output. The marginal rate of technical substitution (MRTS) measures how much of one input you can give up when you add a little of the other, while holding output constant.
  7. Returns to scale describe what happens when all inputs grow proportionally: output can rise more than proportionally (increasing), proportionally (constant), or less than proportionally (decreasing).
  8. Technological progress shifts the production function upward, so the same inputs produce more output.

The appendix extends the chapter with specific functional forms: the Cobb-Douglas function, the Leontief (fixed-proportions) function, and the “production mountain” view of isoquant maps.

1.1.1 Key Definitions

  • Production function: the relationship between inputs and the maximum output they can produce.
  • Long run: the period long enough for all inputs to be varied.
  • Short run: the period during which at least one input cannot be varied.
  • Variable input: an input whose quantity can change in the short run.
  • Fixed input: an input whose quantity cannot change in the short run.
  • Total product (TP): total output as a function of the variable input.
  • Marginal product (MP): the change in total output from one more unit of the variable input.
  • Average product (AP): total output divided by the quantity of the variable input.
  • Isoquant: the set of all input combinations that produce the same level of output.
  • MRTS: the rate at which one input can replace another while output stays the same.
  • Returns to scale: how output responds when all inputs are scaled up by the same proportion.

1.1.2 Key Formulas

With labor \(L\) as the variable input and capital \(K\) fixed in the short run:

\[ AP_L = \frac{Q}{L}, \qquad MP_L = \frac{\Delta Q}{\Delta L} \]

For two inputs, the marginal rate of technical substitution is

\[ MRTS_{LK} = -\frac{\Delta K}{\Delta L}\bigg|_{Q \text{ fixed}} = \frac{MP_L}{MP_K} \]

Returns to scale are determined by multiplying every input by a constant \(c > 1\) in \(Q = F(K, L)\):

\[ F(cK, cL) \begin{cases} > cF(K, L) & \text{increasing returns} \\ = cF(K, L) & \text{constant returns} \\ < cF(K, L) & \text{decreasing returns} \end{cases} \]

For the Cobb-Douglas function \(Q = AK^{\alpha}L^{\beta}\), the sum \(\alpha + \beta\) tells you the returns to scale: greater than 1 is increasing, equal to 1 is constant, and less than 1 is decreasing.

For the Leontief function \(Q = \min(aK, bL)\), inputs must be used in fixed proportions.

1.1.3 Important Relationships

  • When \(MP_L > AP_L\), \(AP_L\) is rising. When \(MP_L < AP_L\), \(AP_L\) is falling.
  • \(MP_L\) intersects \(AP_L\) at the maximum of \(AP_L\).
  • Total product is maximized where \(MP_L = 0\).
  • Along a single isoquant, MRTS falls as you move down and to the right for a convex isoquant. This is the “diminishing MRTS” property.
  • Perfect substitutes: the isoquant is a straight line, and MRTS is constant.
  • Perfect complements: the isoquant is L-shaped, with a corner at the fixed input proportion.

1.1.4 Common Mistakes to Avoid

  • Calling the law of diminishing returns a claim that output falls. Output can still rise; the increase is just smaller each time.
  • Confusing returns to scale (all inputs change) with diminishing returns (one input changes).
  • Assuming a higher average product means a higher marginal product. When AP is rising, MP is above AP, but MP itself can be falling.
  • Reading the allocation rule as “put the input where it is most productive on average.” The rule uses marginal product.

1.2 Practice Questions

1.2.1 Part A: Multiple Choice

Question 1. A factory has two machines that are fixed for the year. It can hire more or fewer workers at any time. Which statement best describes the situation?

  • A. The firm is in the long run because it can change its labor input.
  • B. The firm is in the short run because at least one input (the machines) cannot change.
  • C. The firm is in the long run because it can change its output.
  • D. The firm is in the short run only if it has a single worker.
Answer Key

Answer: B. The short run is defined by at least one fixed input. Here the machines are fixed, so the firm is in the short run. Labor can change, but that does not make the period long run.

Question 2. On a graph of average product of labor (AP) and marginal product of labor (MP) against labor, which statement is correct?

  • A. AP reaches its maximum where MP is at its maximum.
  • B. AP reaches its maximum where MP crosses AP.
  • C. AP reaches its maximum where total product is at its maximum.
  • D. AP reaches its maximum where MP equals zero.
Answer Key

Answer: B. When MP is above AP, AP is rising. When MP is below AP, AP is falling. So AP peaks where the two curves cross. Total product peaks where MP = 0, which is a different point (option C and D confuse the two).

Question 3. A manager has 10 workers to split between two production lines. At the current split, the marginal product of a worker on Line A is 12 and on Line B is 18. Which action best improves output, assuming workers can be moved one at a time?

  • A. Move a worker from Line A to Line B.
  • B. Move a worker from Line B to Line A.
  • C. Keep the current split, because total output is already at its maximum.
  • D. Move workers so that the average products on both lines are equal.
Answer Key

Answer: A. Moving a worker from a line where MP is 12 to a line where MP is 18 adds more output than it removes. The allocation is efficient only when MP is equal across lines. Option D uses average products, which is the wrong comparison.

Question 4. A new production technique lets a firm make 50 more units of output from the same amount of labor and capital. What does this represent?

  • A. A movement along the existing production function.
  • B. An upward shift of the production function (technological progress).
  • C. A move from the long run to the short run.
  • D. Increasing returns to scale.
Answer Key

Answer: B. The same inputs now produce more output, so the production function has shifted up. A movement along a fixed function would require changing inputs. Increasing returns refer to scaling all inputs, which did not happen.

Question 5. Which statement about isoquants is correct?

  • A. Two isoquants for the same firm can cross, because a firm can produce different outputs with the same inputs.
  • B. Isoquants for higher output levels lie closer to the origin.
  • C. For perfect substitutes, the isoquant is L-shaped, and for perfect complements, it is a straight line.
  • D. For a convex isoquant, the MRTS falls as one moves down the curve, because the input being given up becomes more valuable.
Answer Key

Answer: D. Isoquants for different output levels do not cross, and higher outputs lie farther from the origin, so A and B are false. Perfect substitutes give straight-line isoquants and perfect complements give L-shaped ones, so C has the shapes reversed. The statement in D describes the diminishing MRTS.

Question 6. A firm doubles all of its inputs and its output rises from 100 units to 180 units. Which statement is correct?

  • A. The firm has constant returns to scale.
  • B. The firm has increasing returns to scale.
  • C. The firm has decreasing returns to scale.
  • D. The firm is in the short run, so returns to scale do not apply.
Answer Key

Answer: C. Doubling inputs should double output under constant returns. Output rose by only 80 percent (to 180 from 100, which is 1.8 times the original), so output rose less than proportionally. That is decreasing returns to scale. Returns to scale apply when all inputs change, which is the case here, so D is wrong.

1.2.2 Part B: Calculation Questions

Question 7. A firm uses labor \(L\) as its only variable input, with capital fixed. The total product of labor is shown in the R table below.

  1. Find the labor level at which \(AP_L\) is at its maximum, and its value.
  2. Find the labor level at which total product is at its maximum, and explain why it is different from the labor level where \(MP_L = 0\).
  3. Is the law of diminishing returns in effect over the range shown? Explain.
Answer Key

(a) \(AP_L\) is 12 at \(L = 1\), 14 at \(L = 2\), 14 at \(L = 3\), 13 at \(L = 4\), and lower after that. The maximum is 14, reached at \(L = 2\) and \(L = 3\) (tied). At \(L = 3\), \(MP_L = 14\) equals \(AP_L\), which is consistent with the rule that MP crosses AP at AP’s maximum.

(b) Total product is highest at the largest labor level shown, \(L = 6\), where \(TP = 60\). But \(MP_L\) is still positive there (\(MP_6 = 2\)), so output is still rising, just more slowly. Total product is maximized where \(MP_L = 0\), which lies beyond \(L = 6\) in this data. The table shows the maximum only because the data stop at \(L = 6\).

(c) Yes. \(MP_L\) rises from 12 to 16 (up to \(L = 2\)) and then falls from 16 to 14, 10, 6, 2. After \(L = 2\), each additional worker adds less output than the one before, which is diminishing returns.

Question 8. A firm’s production function is \(Q = K^{0.5}L^{0.5}\).

  1. Find \(MP_L\) and \(MP_K\).
  2. Find the marginal rate of technical substitution, \(MRTS_{LK}\), and explain what it means at \(K = 16\), \(L = 4\).
  3. What are the returns to scale? Justify your answer.
Answer Key

(a)

\[ MP_L = \frac{\partial Q}{\partial L} = 0.5\,K^{0.5}L^{-0.5}, \qquad MP_K = \frac{\partial Q}{\partial K} = 0.5\,K^{-0.5}L^{0.5} \]

(b)

\[ MRTS_{LK} = \frac{MP_L}{MP_K} = \frac{K}{L} \]

At \(K = 16\) and \(L = 4\), \(MRTS_{LK} = 16/4 = 4\). This means that, at that point, the firm can give up 1 unit of capital and replace it with 4 units of labor while keeping output unchanged. Equivalently, one unit of labor replaces 0.25 units of capital.

(c) Constant returns to scale. Replace \(K\) and \(L\) with \(cK\) and \(cL\):

\[ Q' = (cK)^{0.5}(cL)^{0.5} = c^{0.5 + 0.5}K^{0.5}L^{0.5} = cQ \]

The exponents sum to \(\alpha + \beta = 0.5 + 0.5 = 1\), so output scales exactly with inputs.

Question 9. A Leontief production function is \(Q = \min(2K,\ 3L)\).

  1. How many units of labor are needed with 6 units of capital to produce 12 units of output?
  2. If the firm has 6 units of capital and 6 units of labor, what is its output? Which input is in excess?
  3. What is the MRTS along any isoquant of this function?
Answer Key

(a) With \(K = 6\), \(2K = 12\). To produce \(Q = 12\) you need \(3L \ge 12\), so \(L = 4\). With exactly this combination, both inputs are fully used.

(b) \(Q = \min(2 \times 6,\ 3 \times 6) = \min(12, 18) = 12\). Capital is the binding input (its limit is 12), and labor has 6 units but only 4 are needed. Labor is in excess by 2 units.

(c) The isoquant is L-shaped, with a corner where \(2K = 3L\). Along the vertical and horizontal segments, one input can change while output stays the same. The MRTS is 0 or undefined there, which means the inputs are not substitutes. At the corner, the inputs must be used together in the fixed proportion \(K/L = 3/2\). So MRTS does not describe substitution for perfect complements.

Question 10. A firm has 10 workers to split between two plots of land, A and B. The marginal product of labor on each plot is

\[ MP_A = 20 - 2L_A, \qquad MP_B = 12 - L_B \]

where \(L_A + L_B = 10\). Find the allocation that maximizes total output, and the marginal product on each plot at that allocation.

Answer Key

Efficient allocation requires equal marginal products:

\[ 20 - 2L_A = 12 - L_B \]

Substitute \(L_B = 10 - L_A\):

\[ 20 - 2L_A = 12 - (10 - L_A) = 2 + L_A \quad\Rightarrow\quad 18 = 3L_A \quad\Rightarrow\quad L_A = 6 \]

So \(L_B = 4\). Check: \(MP_A = 20 - 12 = 8\), and \(MP_B = 12 - 4 = 8\). The marginal products are equal, so no reallocation can add output.
